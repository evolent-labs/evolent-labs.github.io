Configuration

The out of the box configuration for Evolent Boosting.

Evolent Boosting is configured in two places. config.lua holds the framework specific settings, and everything else is edited live through the in-game Admin menu on the tablet.

Framework config

These settings live in config.lua and need a resource restart after a change.

Admin menu config

Edited in game

You don't edit this file by hand. Open the tablet, go to Admin, and change the values there. The JSON below is the out of the box configuration for reference.

Missions config

The missions that ship with the resource, as configured under Admin > Missions. See Custom Missions to add your own steps.
